🎯 MPC Framework

1Prediction Model

Discrete-time system dynamics model used to predict future system states over the prediction horizon

x(k+1) = Ax(k) + Bu(k)

2Cost Function & Constraints

Define the optimization objective and constraints:

• Minimize tracking error and control effort
• Input constraints (u_min ≤ u ≤ u_max)
• State constraints (optional)

3Receding Horizon Optimization

Over the N-step prediction horizon, simultaneously optimize all future control inputs U = [u₀, u₁, ..., u_{N-1}]

Solve a global optimization problem, not a greedy step-by-step approach

4Feedback Correction

Apply only the optimal control input at the current time step u₀, then re-optimize at the next time step to eliminate model mismatch

This is the essence of "Receding Horizon": the optimization window rolls forward with updated measurements

📐 Standard Quadratic MPC Optimization Problem

min Σᵢ₌₀^(N-1) [||x(k+i) - x_ref||²_Q + ||u(k+i)||²_R]

subject to:
  x(k+i+1) = Ax(k+i) + Bu(k+i)
  u_min ≤ u(k+i) ≤ u_max
  x(k|k) = x(k) [current measured state]
